# R19 R3｜檔名安全與離線操作候選｜NOT RELEASED

**這是 Draft PR 的工程候選，不是目前 Suite 17.4.0 的新正式入口。** 原本 R19 R2 及 R17.2 引擎、已發行工具資產維持不變。

## 為什麼開發？

先前 R19 的 `safeDisplayName` 只去除一般控制字元；特殊 Unicode 方向字元 U+202E、U+2067 等仍可造成視覺顯示誤導，長檔名截斷亦可能把 `.md` 等副檔名切掉。這是**檔名顯示可信度**問題，不能誤報成 XSS、讀取任意本機檔案或向外傳送資料。

## 改動範圍（不改正式原始碼）

- 新增獨立 `src/r19/first_result_studio_r19_r3.js`：只清理 **不可信任檔名的顯示標籤**，移除指定不可見控制與 bidi 控制、用 `<bdi dir="auto">` 包住檔名、截斷仍保留副檔名。
- 偵測有移除控制字元時顯示提示；截斷時明講「已縮短顯示」。正常繁中、阿拉伯文字、組合符號與 emoji ZWJ 保留。
- 新增獨立 builder 與 `TW_First_Result_Studio_R19_R3_CANDIDATE_20261113.html`，來源及成品必須逐位元組一致。
- `File.name` 本體、真正副檔名白名單、原始 File bytes、錯誤匯入保留、staged accept/cancel、CRLF、文件的選詞決策與正式 R19 R2 HTML **不改**。
