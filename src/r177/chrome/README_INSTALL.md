# TLS MRFT R17.7 multi-region DOM preview 0.1.0

Extract this ZIP into a new directory. Open chrome://extensions in desktop Chrome, enable Developer mode, choose Load unpacked, and select the extracted directory containing manifest.json. Open an ordinary public HTTP(S) document, click the extension icon (or press Alt+Shift+M), confirm the unchecked public/non-sensitive consent, and choose Enable for this tab. Navigation requires fresh activation. The Stop this tab action or Close all clears the document session; repeated activation replaces it.

Draw up to eight rectangles. FOLLOW_DOM follows the captured original element; removed, replaced or identity-changed elements require Rebind. FIX_VIEWPORT keeps screen coordinates and reads newly entering text on scroll. Use Move and Resize handles (pointer or arrow keys; Shift changes ten pixels), per-region Pause/Resume/Remove, Rebind, language and route selectors. Escape cancels drawing. Collapse the panel to expose more of the page. Ordinary page clicks pass through the frames except their controls. Source is never rewritten.

Default USER_PASTED route: paste a translation of the currently displayed source and choose Use pasted translation. A source/configuration change invalidates it. LOCAL route: choose Prepare local model in the region. Browser availability may be MODEL_UNAVAILABLE or UNSUPPORTED_PAIR. A model download requires the separate unchecked permission and another explicit prepare action. Downloads can use network and disk; no remote translation fallback exists. No real-model quality or Taiwan semantic certification is claimed.

Only visible ordinary HTML glyphs are read. Forms, editable/hidden/inert content, known private/chat/account/payment markers, code, media, frames and shadow roots are excluded before text access. Resource bounds fail closed. Generic DOM cannot identify all unlabelled private content or every same-element virtual-list identity change. Consent is only suitable for public non-sensitive pages. No OCR, screenshot, canvas reading, page-world bridge, telemetry, text storage or background activation. The control panel uses Shadow DOM to isolate styles; it is not a confidentiality boundary from scripts already running on the page. Model preparation and download consent require trusted user controls; synthetic page-triggered clicks cannot grant them. Visible glyph checks use ordinary hit testing; unusual CSS/compositing can exceed this preview’s ordinary-HTML support boundary. Inline technical URLs/templates/JSON are rejected rather than partially transformed. Desktop extension preview; touch drawing in the fixture is not a mobile-extension support claim.

Run the original fixture with Python from this extracted directory: `python -m http.server 8765 --bind 127.0.0.1`, then open http://127.0.0.1:8765/docs/mrft/MRFT_ORIGINAL_FIXTURE.html. Its own explicit enable uses the same production modules. It contains synthetic trap markers and dynamic paragraphs, not third-party content or a fake translator. Alternatively activate the extension on the fixture without its separate demo enable.
