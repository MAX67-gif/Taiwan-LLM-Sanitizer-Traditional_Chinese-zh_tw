# R17.3 自願試用與撤回說明｜純本機紀錄（尚無真人受試者）

只邀請自願參與者使用**自己有權使用的原創短 Markdown**。不得蒐集真實姓名、Email、IP、私人文章、完整路徑、文字/檔案雜湊、模型憑證或客戶文件。使用者可以拒絕試用；不同意不代表失敗。此檔只是可選模板，不會自動送出或建立表單。

- 題目版本：先凍結原始案例，後來不能依照結果重排；第一次使用10人、7天再訪固定5人的既定目標不變。
- 口頭告知：要完成什麼、用途、退出方式、資料保存期及誰能看到匯總；只做手動詢問，沒有追蹤像素與背景紀錄。
- 若同意，只記任務完成（是／否）、秒數、卡點分類、是否有用語建議及當事人可公開的去識別摘要。私人原稿不應交給研究者。
- 有意再使用 ≠ 已完成第二次工作。第二次完成只能依自願者清楚回報，必要時仍註明 SELF_REPORTED。
- 若要求撤回，**對可定位的未公開本機紀錄**刪除並更新匯總的撤回數；若完全匿名無法定位，必須事先清楚告知無法精準撤回單筆（匿名識別不等於個資零風險）。
- 不用試用者身份或 GitHub Clone/CI download 數字來填補沒有人願意參與的空白分母。

對外分享前需要另經合法授權及人工審查；輸入格式見 `consent_schema.json`。不執行招募、不會自動連線。
