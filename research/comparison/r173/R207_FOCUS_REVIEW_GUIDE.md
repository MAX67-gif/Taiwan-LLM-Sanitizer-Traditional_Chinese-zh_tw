# R207｜臺灣用語「專注逐筆審稿」離線工作台

**版本定位：研究預覽／離線單檔 HTML／無網路傳輸／無使用者資料留存／不修改已發行 Suite 17.4.0。**

## 為什麼要做？

R204 已有搜尋、篩選、復原／重做與逐項差異，但一份文件出現多個候選時仍會同時顯示多張卡片。R207 新增**單筆專注模式**：一次只看到一個候選位置，依現有篩選與搜尋做明確的上一筆／下一筆切換，降低第一次使用者需要掃視的資訊量。這不是翻譯模型，也不會幫使用者判斷語義。

## 新增功能

1. **單筆模式切換**：預設仍是 R204 完整列表；手動啟用後僅渲染一筆，隨時切回全部清單。
2. **上一筆／下一筆**：只切換目前顯示的卡片；對應 Alt+K 與 Alt+J。游標在輸入框、搜尋框、選單時不攔截快捷鍵。
3. **人工決定後顯示下一筆未決項目**：只有在使用者親自按「採用／保留／重設」後切換顯示；不會自動採用下一筆的任何選項。
4. **不虛報完成**：單獨顯示已列出候選的待決數量、未列出的超限候選數量、及「已列位置完成也不是全文語義認證」的限制。
5. **相容原有工作流**：保留 R204 的復原／重做、狀態篩選、搜尋、來源變更失效、嚴格 UTF-8、R203 同源接續 JSON、差異預覽與原稿另存。
6. **小螢幕防呆**：390／768／1365px 寬度的實際 Chromium 回歸；不應出現視窗橫向溢出或按鈕消失。

## 檔案及執行

- `research/comparison/r173/review_focus_r207.js`：界限檢查、專注游標、未決項目、部分涵蓋提示，不改稿。
- `research/comparison/r173/review_focus_ui_r207.js`：R204 UI 的新版本分支；保留舊版原始碼不變。
- `research/comparison/r173/build_review_focus_r207.js`：以 R204 Builder 原始輸出為基底，只組裝新的專注 UI 與有限新增元素／CSS，產生 `TW_Review_Focus_R207_20261124.html`。
- `research/comparison/r173/test_review_focus_r207.js`：原生 Node 正反測試、來源覆蓋、無自動改稿／無傳輸。
- `research/comparison/r173/test_review_focus_browser_r207.py`：真實 Chromium `file://` 十情境，自動化不冒充作業系統原生選檔取消。

可檢查 `node research/comparison/r173/build_review_focus_r207.js --build`、`node research/comparison/r173/build_review_focus_r207.js --check`，然後以瀏覽器開啟產出的 HTML。研究工作台可以處理原創／自有權利的文件；**無權利的第三方資料不應任意重製**。

## 已知限制與風險

- `MAX_CANDIDATES=120`，超出時必須明確顯示 `PARTIAL_COVERAGE_NOT_FULLY_REVIEWED`；已列 120 項全部決定也不等於全文已審核。
- 本工具只在介面中縮減顯示，保留候選來源與所有實際選擇。鍵盤快速切換不能繞過人工按鈕或覆蓋歷史。
- 此功能不是對 R194/R196 的通用語境分類，不收集真人評語，不宣稱詞彙判斷正確率。
- 不使用 CDN、API、localStorage、雲端模型、遙測或自動寫回原始檔。審稿紀錄包含雜湊與選項 ID，仍須依敏感資料保護。
- 17.5.0 正式套件、跨語系 Release 目錄與完整新版本發布流程尚未完成；R207 只是研究預覽，不可透過既有 17.4.0 發行器當成新工具發布。

## 成功路徑、踩雷、可重用規則

**成功路徑：** 先以現有 R204 的手動決定和嚴格來源綁定做基礎；新功能只改 View，不擅自改 Data 或 Choice；保留原始 R204 舊程式可獨立回退。實際 Chromium 以 `file://` 驗證核心互動，與既有 R204 回歸一同跑。

**踩雷：** 畫面看起來只剩一筆不代表其他候選已被處理；搜尋結果為零也不是完成。來源變更或讀檔競態要服從 R204 原有取消時鐘，不可因新增快速鍵而繞過。

**可重用規則：** 以「保護 → 衝突 → 未知保留 → 人工確認」優先，所有自動化僅導航，不作語義裁決。任何新 UI 功能均需證明不影響舊的 R203/R204 接續與原稿不覆寫保護。
