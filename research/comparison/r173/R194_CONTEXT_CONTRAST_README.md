# R194 臺灣用語語境正反例研究｜Context Contrast Lab（Shadow）

**狀態：研究用／非正式詞庫／不可自動改寫／未經真人語言審核。**

## 目前有什麼

- 原創 **52 組術語正反語境**，共 104 個有情境的自寫例句，另有 52 個人工設計的程式碼保留示例。
- 橫跨軟體 UI、API、Git、終端機、網路、資安、雲端、媒體、財務、餐飲、法律、旅遊與生活。
- 機器可檢查的 JSON 結構：`research/comparison/r173/context_contrasts_r194.json`。
- 唯讀驗證與四狀態的原創測試路由：`research/comparison/r173/context_contrasts_r194.js`。
- 既有 `tests/test_comparison_r173.js` 內新增 6 組防回歸測試，覆蓋每組正例、反例、保護例與未知例。
- 所有判斷都只是**精確比對測試語料**，不是可用在任意新句子的語意辨識器。

## 正反語境為何重要？

| 術語 | 正例語境 | 不可套用同一詞的反例 | 類別 |
| --- | --- | --- | --- |
| `menu` | 軟體選單 | 餐廳菜單 | UI／餐飲 |
| `thread` | 執行緒 | 討論串 | OS／社群 |
| `token` | API 權杖 | 分詞器詞元 | 資安／AI |
| `default` | 預設值 | 借款違約 | 設定／契約 |
| `质量` | 翻譯品質 | 物體質量 | 內容／物理 |
| `设置` | 設定頁 | 置放設備 | UI／實體 |

上表是**由我們撰寫的研究例句與候選說法**，不是第三方完整詞庫，也未經母語者審核。選詞不是二元的「替換／不替換」，還需確認是否有語境衝突、是否為受保護結構、是否根本無法判讀。

## 四種狀態

- **PREFERRED_SUGGESTION**：已知原創正例與候選說法；只能建議，不能替使用者按確認。
- **COUNTEREXAMPLE_BLOCK**：反例出現時，擋住同一條正例替換。
- **PROTECTED_KEEP**：程式碼、JSON Key、佔位符、URL、命令語法等必須先行保護。
- **UNKNOWN_KEEP**：未知句子或未識別語境保留原文，不自動擴張詞庫。

## 結構、權利及隱私邊界

`schema=tls.r194.context-contrast-research.v1`，每筆正反例均須存在、不同、含原術語，並附 `ORIGINAL_SYNTHETIC_EXAMPLE`、`NEEDS_HUMAN_REVIEW`。不得導入抓取的第三方詞典或私人原稿；不能把工程結構測試視為翻譯自然度、語意等價、正確率、採用率或 OpenAI 專案入選證據。

驗證器只回傳統計中繼資料，不包含任何使用者文字、範例全文或檔案路徑。操作上限、版本與拒絕條件以程式驗證器為準。

## 後續可落地的創意

1. **語境配對教學卡**：同個詞顯示正例、反例、保留原詞，不提供一鍵全域改寫。
2. **術語四態路由**：優先建立 Protected → Contradicting → Candidate → Unknown 的優先序，避免「看到字就替換」。
3. **學習型正反例審查**：使用者回報必須同時提供新正例、反例、來源授權與取消條件；不能直接改動 approved 詞庫。
4. **低認知負擔 UI**：只顯示最必要的候選與反證線索，例外與限制可展開；不讓幾十個選項同時轟炸新手。
5. **未來版本驗收**：獨立對照有權處理的真實作品，建立新鮮、未曝光反例，人工判讀後才能評估是否進正式產品。

以上是研發方向，**本次尚未把這套研究接上正式 R19 或 17.4.0 Runtime**。
