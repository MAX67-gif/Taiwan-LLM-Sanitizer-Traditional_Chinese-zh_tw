# 詞庫與臺灣用語選擇

## 不是禁語清單

你可以選擇保留原本的中國用語、臺灣用語、英文名稱或專有名詞。翻譯只在有足夠語境時建議替代寫法，不應將一種說法當作唯一標準。

例如：`menu` 在網站操作介面可能是「選單」，在餐廳頁面可能是「菜單」。你可以依網站或工作用途挑選偏好，或保留 `menu` 不動。

- [離線詞庫探索器](../examples/TW_Lexicon_Explorer_R3_20261024.html)：可在自己電腦打開、搜尋、篩選，沒有遠端查詢。

候選詞不一定準確，也不是官方辭典認證。請將「使用偏好」與「語言正誤」分開。

## 一起改善

提交詞條請包含：原文、提議寫法、**適用情境**、至少一組正例及反例、可合法使用的來源說明。如果同一詞可以合理翻成兩種意思，請列出各自領域，不要用全域硬替換。

請勿將未取得再授權權利的第三方詞典、書籍、企業文件直接搬進公開 MIT 詞庫；詞彙本身與受保護的原創編排／例句／資料庫需要分別判斷權利。

詞庫的公開版本及歷史提交依此倉庫授權使用；使用者可依法重用。你不必分享自己的網頁、個人翻譯紀錄或客戶文件才可以使用工具。

## R10 的來源追溯與反例審查

[R10 離線來源審查工作台](../examples/TW_Context_Governance_Lab_R10_20261024.html) 收錄 40 筆**專案自行撰寫、未獲獨立語言審核**的例句：其中 28 筆直接追溯 R9 原創資料、12 筆是新編輯草稿。每筆公開正例、反例、風險及來源欄位；仍然只有 `SUGGEST_ONLY`，不得升級 R3 的自動規則。使用者可手動選擇與匯出自己的審稿備註，不涉及文字審查或強制替換。詳見 [公開審查規格](R10_PROVENANCE_REVIEW.md)。
