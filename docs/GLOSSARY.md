# 詞庫與臺灣用語選擇

## 不是禁語清單

你可以選擇保留原本的中國用語、臺灣用語、英文名稱或專有名詞。翻譯只在有足夠語境時建議替代寫法，不應將一種說法當作唯一標準。

例如：`menu` 在網站操作介面可能是「選單」，在餐廳頁面可能是「菜單」。你可以依網站或工作用途挑選偏好，或保留 `menu` 不動。

## 一起改善

提交詞條請包含：原文、提議寫法、**適用情境**、至少一組正例及反例、可合法使用的來源說明。如果同一詞可以合理翻成兩種意思，請列出各自領域，不要用全域硬替換。

請勿將未取得再授權權利的第三方詞典、書籍、企業文件直接搬進公開 MIT 詞庫；詞彙本身與受保護的原創編排／例句／資料庫需要分別判斷權利。

詞庫的公開版本及歷史提交依此倉庫授權使用；使用者可依法重用。你不必分享自己的網頁、個人翻譯紀錄或客戶文件才可以使用工具。
