# Privacy-First Translation Contract R3｜使用者隱私最高優先（2026-10-24）

## 產品承諾與可檢查範圍

**本專案自有程式不得收集、分析、儲存或傳送使用者造訪網站、正在閱讀的文章、原始文字、翻譯結果、帳號、Cookie、密碼、鍵盤輸入、IP 地址、個人檔案及瀏覽歷程。** 不提供廣告追蹤、背景遙測、使用者指紋、隱藏事件上報。詞庫僅本機執行，使用者不必註冊。一般網頁顯示修改的還原紀錄只存在該頁記憶體，停用即釋放；不存全文。

真正的安全是可驗證的工程契約，不是宣傳用「百分之百絕對安全」字句。

### 目前 R2/R3 實作邊界

- Chrome 啟用每個網站須先取得使用者授權；設定資料僅保存為 `origin + 模式 + 來源語言`（這本身是**站點設定資訊**，不能說完全沒有任何本機儲存）。可停用與清除 Chrome 擴充功能儲存資料。
- Tampermonkey 只存每站是否啟用、偏好模式／語言（GM 本機設定）；腳本包必須自含、禁止 `@require` 遠端程式碼。
- `Node.js CLI` 僅在使用者指定目錄下讀來源、另輸出檔案；此為**使用者主動保存的轉換結果**，與軟體偷偷蒐集不同。禁止預設傳雲端或自動覆寫原檔。
- Chrome 內建 Translator API 屬瀏覽器本機翻譯模型；首次使用可能**由瀏覽器下載語言模型／語言包**。不能因此對外宣稱「安裝後完全不需要任何網路連線」，但本專案不提供外部翻譯 API 文字上傳。
- 網站與瀏覽器本身可能另有網路活動，本專案無法替它們保證隱私。

## 資料路由狀態

`LOCAL_TERMS` → 直接本地處理。
`LOCAL_BROWSER_MODEL` → 使用者主動選擇，Chrome 可用時載入語言包、本機翻譯。
`MODEL_NOT_AVAILABLE` → 保留原文或詞彙 fallback，不私自改遠端。
`UNSUPPORTED_OR_PROTECTED` → 網頁表單、私密輸入區、canvas 等跳過。
`REMOTE_OPT_IN_FUTURE` → **尚未實作**；未來若有，必須逐次明確說明接收方、傳送內容、保存、成本、撤回權，預設關閉且不能讓隱私模式意外外傳。

## 威脅模型與失敗保護

1. 公開原始碼與第三方依賴供檢查；Chrome MV3 禁止遠端執行程式碼。
2. 盡可能要求最少權限（user gesture、per-site origin），不能偷讀全網內容。
3. 跳過 script/style/code/input/textarea/contenteditable/translate=no 等；不主動記錄登入頁、使用者鍵入訊息。
4. 不使用 `fetch / XMLHttpRequest / sendBeacon / WebSocket` 傳輸翻譯資料；CI 建議檢查依賴與權限變更。
5. 大型頁面與異步工作需節流、取消、上下文狀態隔離、拒絕壞掉的模型回傳，不注入任意 HTML。
6. 網頁本身可能操控 DOM 與 CSS；Overlay／Hover 原文的公開 UI 不應洩漏被標為敏感的內容或超出使用者允許的頁面。
7. 未來任何遙測、跨網域傳輸或新權限必須更改 Privacy 文件、版本、使用者操作流程，經明確使用者授權才可啟用。

## 「沒有資料蒐集」與社群改善如何並存？

改善來源只能是**使用者自願提交**的字詞提案、去識別化範例、公開 GitHub Issue/PR，以及 GitHub 已公開的下載/Star 數，不植入追蹤像素、匿名 Fingerprinting 或背景統計。Issue 頁應提醒不貼出敏感資料；無人同意不得分享私密網頁翻譯結果。

## 不准誤導

「本程式不自行上傳網頁內容」可以在通過網路稽核後聲明；「我們的程式使任何網站、Chrome、第三方 AI 100% 無資料傳輸」是超出控制範圍的說法，不得聲稱。
