# R9｜四段式階段檢視

## 目前目標
把「收集很多詞」提升成「讓使用者能檢查語境、否決錯誤改寫、帶走自己的用語選擇」。維持各地語言差異中立、使用者控制與 MIT Open-Core。

## 已確認限制
R5 v0.4.0 通用執行期、R6 凍結 100 題、R7.1 非官方獨立示範、R8 原單檔都不能被 R9 覆蓋。R9 只能在獨立本機頁面做逐項審閱，沒有正式 Chrome/網站全域套用、AI 文風控制、全文 NLP 證據。公開倉庫不得提交任何私人附件或遊戲素材。既有 publication guard 禁止敏感路徑及未列名文件。

## 本輪工作內容
新增純本機使用者詞彙 Schema、可攜 JSON 匯入／匯出、必須手動逐位置選擇的預覽、比對清單、28 組原創正反情境例；以 R3 950 個既有詞作提示但不自動升級。新增單檔可重現建置、Node 測試與 Chromium 回歸、GitHub Actions 建置及發行流程。**是否全數通過以對應 PR／主線 CI 為準，文件不代替驗收紀錄。**

## 下一步
第一優先：用乾淨且可分享的文字樣本取得使用者實際操作回饋，先處理「選錯語境」「保存造成意外套用」「特殊詞破壞語法」的案例，再進入逐站整合。停止用未驗證候選增加字數來替代自然中文品質證據。
