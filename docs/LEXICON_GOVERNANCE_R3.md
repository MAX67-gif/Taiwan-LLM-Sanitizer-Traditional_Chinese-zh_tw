# Taiwan-LLM-Sanitizer｜臺灣語境詞庫治理 R3（2026-10-24）

## 一、核心原則：詞彙不是禁語名單

本專案研究臺灣（zh-Hant-TW）與中國大陸（zh-CN）等地區使用習慣的差異，**不是審查或消滅任何地區、政治觀點或社群的語言**。所有用語原則上可以保存、比較、保留原文與自訂。使用者可選擇：不轉換、建議模式、臺灣偏好模式、特定領域模式、建立個人詞庫；不以某個詞出現在中國就宣稱它在臺灣「禁止使用」。

「來源地區／領域／建議偏好」是描述語言現象，不是語言正統性或政治判斷。

## 二、目前數據的真實意義

- `lexicon/candidates_r3.json`：**883 個編輯提出的待審核候選詞條**，涵蓋 16 個領域，`review_status=candidate`、`automation=suggestion_only`，不會加入自動取代。候選詞可能有錯、地區交疊、罕見性差異；**不是官方用語表或已查證統計**。
- `lexicon/approved_r3.json`：**67 個保守編輯種子詞條**，其中 35 個可依預設保守執行，其餘 32 個只在明確領域下套用。其狀態是 `editorial_seed_not_externally_verified`，不是政府認證或社群已確認。
- `src/core/lexicon_pack.js`：精簡的瀏覽器執行詞庫，由 `tools/generate_lexicon_r3.py` 保持與 JSON 同步。
- 老版本原有 R2 確定性詞彙規則保留；新增詞庫不會覆寫舊授權或其他功能。

### 不能直接全文硬換的例子

| 原文 | 網站導航 | 餐飲情境 | 默認不明語境 |
|---|---|---|---|
| menu | 選單 | 菜單 | 保留 menu |
| 菜单 | 選單 | 菜單 | 保留 菜单 |
| 智能体 | 可建議 AI 代理、智慧代理、Agent，視技術背景 | 不適用 | 保留，或提示確認 |
| 接口 | 可以是軟體介面、API、硬體接頭 | 不適用 | 保留或提供多種候選 |
| 视频 | 影片、短影音、視訊通話視情境 | 不適用 | 保留或提供候選 |

「已認得這個詞」不等於「知道使用者原意」。罕見詞、方言、特殊領域、高專業門檻詞預設先進候選池，不強制自動替換。

## 三、詞條欄位與審核流程

每筆保存 `id/from/to/domain/source_locale/target_locale/review_status/automation/alternatives/evidence_status/note`；日後需加 `sense_id、example_input、example_expected、counterexample、references、license_id、reviewer、reviewed_at、effective_version`。此版本部分欄位尚未提供證據，因此必須標示 `requires_independent_review`。

提案 → 檢查授權／來源 → 提供正例＋反例 → 領域分類（可多義）→ 非歧視或強制禁止審查 → 兩人複核／標示未複核 → 單元測試 → 版本發布。

社群使用者可透過 GitHub Issue／PR **自願提出**詞條，預設不從瀏覽中的任何頁面、聊天內容或翻譯文字上傳例句。若提供例句，請自行移除私人資訊及受著作權保護的不適當內容。

## 四、適配與衝突優先順序

使用者關閉／指定保留 → 個人明確例外 → 該站明確領域偏好 → 已審核的語境轉換 → 預設安全種子詞 → 建議提示 → 原文不變。

模型翻譯不得將詞庫「建議」當成指令，不能改寫 JSON Keys、URL、程式碼、Prompt 的角色邊界、身份資訊。比對時要留下 local-only 差異資訊供使用者可逆回復，避免持久保存原頁內容。

## 五、第三方來源與授權，不得偷貼資料

目前候選詞由本專案獨立編輯提出，**未從第三方詞典批次複製**。可參考公開權威資料做術語驗證，但須逐一確認重製／改作／散布條件：

- OpenCC：https://github.com/BYVoid/OpenCC ，Apache-2.0；若未來整合其資料/程式，需依授權履行 attribution、LICENSE、NOTICE 等適用義務，不能當成自行原創的純 MIT 資產。
- 教育部國語辭典：https://language.moe.gov.tw/ ，部分資料 CC BY-ND 3.0 TW，**禁止改作**；不能直接改寫或翻譯其字典並當 MIT 詞庫發布。
- 萌典兩岸詞典：https://www.moedict.tw/about.html ，標示 CC BY-NC-ND 3.0 TW，包含**非商業＋禁止改作**限制；不得無審核複製進 MIT／商用 Open-Core 詞庫。
- 其他科技術語來源需逐項核對授權，不能因網站公開就認為可自由再發布。

專有名詞、品牌、地方使用習慣與一般事實可能有不同權利狀態；每個資料來源的著作權／商標／授權都需分開處理。

## 六、量化評估

- 詞庫覆蓋：有領域來源、有人工例句的詞條占比，不以詞條總數假裝高品質。
- 轉換精確率：附人工標準答案與至少一個反例的獨立 holdout 範例。
- 錯譯率與過度改寫率：含 menu（導航／餐廳）、接口、視頻與詞彙同形不同義。
- 強制替換誤率與還原失敗率：目標 0，但需用真實回歸證據，不能宣稱已達標。
- 中立性：永不依詞條地域／政治類別觸發禁用、懲罰或替換；唯一適配目標是使用者自行選擇臺灣繁體在地化。

**永遠禁止：將 883 個未審核候選詞全部自動投入主程式，或宣稱它們已經專家驗證。**
