# 接下來會做什麼？

我們希望讓跨國工作、讀取開源文件及日常上網的使用者，都能放心使用自然、好讀的臺灣繁體中文。

以下是公開的**產品方向**，不是已發布功能或承諾日期：

1. **自然中文品質**：以公開合法的例句評估流暢度、忠於原意和臺灣語境，讓使用者有可信的翻譯品質參考。
2. **更好用的閱讀體驗**：探索雙語對照、選取句子翻譯、懸停看原文、一鍵回復等方式；優先不破壞網站操作。
3. **詞彙可自行決定**：提供更容易調整的個人用語偏好、專有名詞例外與可匯入的詞庫。
4. **更多使用場合**：逐步改善 Markdown/HTML 技術文件、Prompt 與結構化資料的安全處理。
5. **每一版都做隱私和相容性測試**：不私自收集翻譯文字；在支援範圍及權限有變更時先清楚告知。

目前沒有全面 OCR、Canvas/WebGL、所有 PDF 或手機擴充功能的完整支援。會依實際成果更新 [功能狀態](FEATURES.md)，不提前把構想寫成已完成。

希望協助測試或提供臺灣自然用語，歡迎從公開的、已去識別化的範例開始；不必上傳你的私人網站或文件。

## R6 品質評測階段（2026-10-24）

- **已提供：** 100 題公開凍結品質回歸資料、SHA256、自動結構驗證、四維人工評分說明、離線雙語審閱頁、桌面 Chrome 本機模型執行入口。
- **未驗證：** 實際瀏覽器能否取得全套語言模型、模型真正的自然中文品質、獨立雙評審覆蓋、不同模型之間的公平比較。
- **下一步：** 先做真實模型可用性與人工雙人評測，再評估選配原文對照覆蓋層；個人詞彙例外、OCR/PDF 維持後續項目。

[了解 R6 評測方法](QUALITY_EVALUATION.md)

## R8 語境審查獨立預覽（2026-10-24）

已建構可離線開啟的單檔 HTML，從 883 筆候選與 67 筆編輯種子提示不同領域、不同譯法及歧義。它只給建議，不自動改寫，故不能取代真實模型的自然語言翻譯與雙人評測。後續優先追查來源權利、收集詞條正反例、建立個人詞彙例外與網站原文對照。
