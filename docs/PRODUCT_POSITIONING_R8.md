# R8｜臺灣本土化語言工具的產品定位與競爭優勢（公開構想）

2026-10-24。這是專案的原創產品策略，**不是 OpenAI 官方立場、真實付費用戶調查或產品上市成績**。

## 市場基準，不誇大獨家性

- DeepL 已支援 Glossary、Style Rules 與 Translation Memory：https://www.deepl.com/en/features/glossary
- Immersive Translate 已提供雙語網頁、懸停翻譯與 PDF：https://immersivetranslate.com/docs/
- Read Frog 已提供網站分組詞庫、雙語閱讀、使用者自訂譯名：https://www.readfrog.app/en/docs/glossary

因此「有詞庫」「雙語顯示」「翻譯網頁」本身不足以構成差異。TLS 的機會應該是可檢驗的**臺灣語境、透明詞源、保留原文、語法不破壞與本機隱私**。

## 主要使用者與價值

1. 一般上網者：點一下轉為看得慣的臺灣中文，原文可回復。
2. 技術文件讀者：可檢視 AI、工程、UI 一詞多義，不毀損 CLI 指令、JSON key、變數、品牌或官方名稱。
3. 臺灣開源維護者：可以查詞、投稿、提交人工覆核與回歸案例，不要求交出私人資料。
4. 臺灣軟體在地化團隊：可用客觀的測試證據維持用語一致性，不是以自動替換字數當成果。

## 五個功能投資優先順序

P0 語境型詞庫／原文保真：每筆有地區、領域、義項、詞源、反例、可覆核狀態，必要時保留原文。R8 的單檔審查工作台是第一步。

P0 品質證據：針對歧義、專名、Prompt role、資料結構保真做負例測試，再做 R6 的真實模型雙評審，沒有數據不宣稱準確率。

P1 個人偏好與逐站例外：原文、自然臺灣化、專業嚴謹用語及使用者自訂詞，提供手動匯入匯出，不做未告知同步。

P1 原文－譯文－理由三欄對照：重要詞顯示來源說法、建議說法、適用領域與反例；明確指出「這是偏好，不是禁詞」。

P2 開發者與社群工作流：Markdown、程式註解、結構化 JSON 字串與 Prompt 審查；輸出安全差異、人工審核、可重現測試與回復能力。

## 避免陷入只堆詞數的誤區

先補齊資料狀態：未審候選、編輯種子、經雙審驗證、可自動使用、應保留原文；同時保存正反例、領域、來源與授權。不符合條件的候選保持研究狀態；數量增加不能跳過證據。

上游詞庫的權利需獨立審查：OpenCC 以 Apache-2.0 釋出；g0v 的兩岸詞庫原始資料可能受 CC BY-NC-ND 限制（即使整理程式採 CC0 也不解除原文限制）；Microsoft 術語搜尋可作人工參考，但下載改作與散布另須查明條款。不得直接宣稱它們都能重新授權成 MIT。

## 可評估指標（尚無實際測量值）

首次使用成功率、可還原率、使用者覆寫率、誤判歧義數、保真錯誤數、真人自然度、每詞來源與正反例覆蓋率、社群審稿覆蓋率。堅持不以私自遙測換取增長數據；若未來要量測，應採清楚告知、明確自願及本機優先設計。
