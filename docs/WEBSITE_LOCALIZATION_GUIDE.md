# 通用網站翻譯與雙語閱讀｜使用者自主選擇

本文件介紹 Taiwan-LLM-Sanitizer 的一般用途，**不是第三方網站、遊戲或商業服務的安裝補丁**，亦不代表第三方權利人授權。

## 1. 先確認網站條款與資料安全

在操作任何第三方網站前，先確認該網站的使用規定、翻譯及介面修改政策。請勿使用工具讀取或提交登入憑證、私密聊天、個人資料、交易資訊或受限制內容。**使用者操作的合法性依具體條款與法律而定；僅在自己瀏覽器顯示譯文，不代表當然獲得授權。**

## 2. 一般網頁的最小使用流程

1. 從本專案經驗證的 [Releases](https://github.com/MAX67-gif/Taiwan-LLM-Sanitizer-Traditional_Chinese-zh_tw/releases) 下載與選擇 **R13 安全雙語閱讀**，按 [Chrome](INSTALL_CHROME.md) 或 [Tampermonkey](INSTALL_TAMPERMONKEY.md) 說明安裝。這些是通用工具，並非特定網站安裝包。
2. 使用者自行決定啟用的網站；**不要**在不允許修改或自動化的服務中使用。只選取有權自行閱讀的普通文字，並在面板內確認原文與譯文。
3. 若瀏覽器本機翻譯模型不支援所選語言，工具會說明限制；亦可手動貼上自己有權使用的譯文。Chrome 可能需要下載模型，請參考 [隱私政策](../PRIVACY.md)。
4. 如需改變個人熟悉的用語，可選擇 R11 逐站個人詞庫，**由使用者逐項核對與確認**；遇到不明語境不要強制修改。
5. 不需要時停用工具並檢查還原。自行保留原始內容；不保證所有網站的 DOM 都能完全還原。

## 3. 哪些情況不適合？

- 由 Canvas、WebGL、圖片或影片直接繪製的文字，通常**不是**工具可辨識的 DOM 文字。不要為了翻譯而擅自修改網站程式、記憶體、存檔、封包或 API。
- 表單、密碼欄、聊天室、其他人的暱稱／資料、帳號管理或其他敏感介面不應交由翻譯腳本自動處理。
- 無權翻譯或公開傳播的遊戲劇情、長篇文字、官方翻譯資料、資源、程式碼與視覺素材，不能因已在瀏覽器可見就納入公開詞庫。
