使用方法：在本地打开独立 HTML，选择文件夹，明确勾选允许读取的 Markdown 文件，再点击检查。未勾选的文件不会被读取。

PASS 代表经过当前保守链接规则验证；WARN 表示大小写等兼容性疑虑；BLOCK 表示已确认的无效链接或不安全路径；UNKNOWN 表示外部链接、未获允许的目标或无法解析的语法。UNKNOWN 不代表成功。

如需严格的本机符号链接与真实路径检查，请选择 Node CLI；浏览器文件选择器无法提供操作系统级符号链接审计。输出为不含正文的元数据，但文件哈希仍可能被猜测。

这不是翻译工具、语义审校、法律授权或数字签名；不联网、不修改源文件、不读取账户或聊天记录。当前仅支持明示允许清单中的 Markdown。
