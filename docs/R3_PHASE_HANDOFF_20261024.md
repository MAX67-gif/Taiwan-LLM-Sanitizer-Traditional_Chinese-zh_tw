# Taiwan-LLM-Sanitizer R3｜階段狀態與接續（2026-10-24）

## 1. 目前目標

提供免費、可自由選擇用語的臺灣繁中通用在地化工具。R3 主線是多領域詞庫擴充、保守語境辨識、可設定偏好、本地批次轉換、完全離線候選詞探索器與可核對的隱私契約。

## 2. 已確認限制

- 第六輪 Open-Core 方案 B：公開核心為 MIT，日後獨立加值模組另授權，不追溯修改 MIT 權利。
- 第九輪多語在地化：保留 Tech-Term Localizer、Context-Aware Prompt Tuner、Structured Data Pipeline 等長期方向。
- 不限網站、遊戲、服務或 Tampermonkey；Chrome/Tampermonkey/CLI 都只是工具的使用介面。
- 大量詞不代表立即自動替換；不設禁語、沒有政治／地區文字審查。
- 本專案不自行搜集用戶頁面內容、翻譯結果、網路行為或背景遙測。使用者明確選擇的本地設定與 CLI 輸出必須透明說明。
- Chrome Translator API 本機翻譯受瀏覽器版本/模型語言包限制；不是所有網頁/Canvas/WebGL/PDF/OCR 自動完整支援。

## 3. 已完成（依 GitHub Actions 驗收狀態）

- 883 筆候選詞、16 個領域，皆僅供建議、待人工驗證，不暗中自動換詞。
- 67 筆保守編輯種子，其中 35 個預設安全候選，32 個領域明確才用；整體仍不應冒稱已全面專家認證。
- 編譯後的 JS 領域詞庫，R2 功能保留，Menu/菜单 與餐廳菜單語境有獨立測試。
- Chrome 與 Tampermonkey 都有來源語言與領域偏好，單站啟用/停用與還原；CLI 加上 `--domain`。
- 完全離線 883 詞探索器，可在瀏覽器直接檢視和搜尋，不需註冊／不送網路。
- 新增詞庫授權治理、產品市場比較、Privacy-First 契約、即時 Overlay 設計文件。
- CI 含 JSON/Pack 一致性、Node/CLI/Provider 回歸、Chromium 動態網頁和詞庫探索器、ZIP 整合/版本校驗。

## 4. 下一步

1. 增加可證據化的人類術語審核和正反例資料，避免候選誤譯。
2. 從實測出發做可選 Overlay：原文/譯文切換、雙語對照、滑鼠懸停，一律可還原、不破壞互動。
3. 做結構安全 Prompt/Markdown/HTML Parser，不改原始程式命令及指令邊界。
4. 建立真實瀏覽器語言包相容矩陣、獨立使用者回報與翻譯品質統計（不蒐集瀏覽內容）。
5. 官方 GitHub 介紹、公開版本標籤、社群貢獻規範與真實 OpenAI Codex OSS 資料整備。

**現階段沒有從用户偷收資料，亦不應宣稱 OpenAI 入選、真實安裝量已達任何門檻或所有語言全部翻譯可用。**
