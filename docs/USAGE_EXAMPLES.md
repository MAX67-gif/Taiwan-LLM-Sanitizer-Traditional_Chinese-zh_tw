# 臺灣繁中工具的九個使用範例（原創／概念示範）

**語言／Languages：** [繁體中文](USAGE_EXAMPLES.md) · [简体中文](USAGE_EXAMPLES.zh-CN.md) · [English](USAGE_EXAMPLES.en.md) · [日本語](USAGE_EXAMPLES.ja.md) · [한국어](USAGE_EXAMPLES.ko.md) · [Español](USAGE_EXAMPLES.es.md)

> 這些句子與網址都是本專案自行編寫的合成範例，**不是任何第三方遊戲、網站或模型的真實截圖、驗證結果或授權內容**。翻譯文字屬人工範例，不是程式自動翻譯成果；各工具目前仍分別操作，尚無單鍵串接的完整流水線。

## EX01｜同一個英文單字，依語境選用不同中文

| 自行撰寫的原文 | 語境 | 臺灣用語候選 |
| --- | --- | --- |
| Open the menu | 軟體操作 | 開啟**選單** |
| Read the menu | 餐廳點餐 | 閱讀**菜單** |
| Click Save | 按鈕操作 | **點選**「儲存」 |
| The camera clicked | 聲音描述 | 相機發出**喀嚓聲** |

R11 可讓使用者自行選擇詞條，不能把 `menu` 或 `click` 不分語境全域替換。**狀態：人工示範，可手動選詞；非模型語意判定。**

## EX02｜R13：一般網站選取文字、只讀對照

自製測試網頁出現 `Open settings to adjust the display.`。使用者**主動選取**這段可見文字，R13 顯示原文，並能在手動貼入譯文或本機 Translator *實際可用* 時顯示候選：`開啟設定以調整顯示方式。`

- 原網站文字不因 R13 選取閱讀而被修改；不保證所有裝置皆支援本機模型。
- 不能因此宣稱已實現整站自動翻譯。**狀態：R13 已有只讀對照；譯文品質與本機模型須逐次核對。**

## EX03｜R11：網站內人工詞庫的保守使用

使用者自己整理 `Settings → 設定`、`Open menu → 開啟選單`，僅在自己選定、條款允許的網站啟用，預覽後同意才套用；隨時可停用或還原（依工具保守還原條件）。

**狀態：R11 手動匯入與逐站確認可用；沒有通用自動詞彙語意判斷。**

## EX04｜R14：無模型時如實顯示不可用

假設裝置對 `en → zh-Hant` 的語言組回傳 `unavailable`。R14 的純離線宣告模擬資料只顯示「不可用／需確認」，絕不偷偷轉向遠端伺服器。要知道**真實裝置是否支援**，需另外使用其本機 API 做實測。

**狀態：獨立離線能力宣告工具；不是實機 Chrome 模型驗證。**

## EX05｜R15：Markdown 說明文字可預覽，指令與 URL 不動

自行撰寫原文：`Run the tool with` + `--help` + `See https://example.org/help.`。人工候選可只改說明文字為「使用 `--help` 執行工具；請參閱 `https://example.org/help`。」；程式區塊、行內程式碼、命令列參數與連結目的地須保護。

**狀態：R15 已有保守片段檢查及人工預覽，但不是完整 Markdown AST；R15.1 針對 HTML 與括號連結的修補是否正式發布應以 Release 頁為準。**

## EX06｜R15：JSON 只允許明確白名單中的顯示字串預覽

原創資料：

```json
{"title":"Help center","url":"https://example.org/help","enabled":true}
```

允許使用者人工預覽 `title` 值變成 `說明中心`；`title` **鍵名**、`url`、`enabled` 等結構不能改。無法證實安全的未知欄位應保留原文。

**狀態：R15 獨立、離線、預覽限定；不會直接改寫 JSON 原始檔。**

## EX07｜R15：Prompt 角色與佔位符不可翻錯

自製片段：

```text
system: Preserve placeholders exactly.
user: Explain the settings for {{ACCOUNT_ID}}.
```

安全目標是保留 `system:`／`user:` 和 `{{ACCOUNT_ID}}`，只讓使用者在安全的說明文字片段進行人工預覽。**不保證變更後的 Prompt 語意與安全性。**

## EX08｜網頁遊戲／互動式網站的「能做／不能做」

這是**虛構介面**：一個一般 DOM 按鈕顯示 `Open settings`，另一段文字顯示 `Start`。

| 畫面實作 | 通用 TLS 可能提供的協助 | 限制 |
| --- | --- | --- |
| 一般 HTML DOM、可選取的公開 UI 文字 | 使用者手動選取後 R13 顯示對照；若網站條款允許，R11 可依使用者自己建立的詞庫、逐站手動預覽 | 不能保證每個實際網站的 DOM 或翻譯品質 |
| Canvas／WebGL 繪製在畫布中的文字 | **目前無法直接翻譯** | 不會反編譯遊戲、Hook 引擎或改寫封包 |
| 玩家暱稱、即時聊天、帳密、存檔 | **排除，不應翻譯或擷取** | 不蒐集個資；不做遊戲操作自動化 |
| 第三方著作權敘事文本、專用翻譯詞庫 | **不提供公開專用內容** | 需要分別確認著作權、商標、遊戲條款與授權 |

**狀態：根據現有工具界線寫出的使用情境；沒有對任何特定遊戲進行端到端驗證，更沒有發布專用套件。**

## EX09｜遇到不支援或權利不明，安全停止

若只看得到圖片中的文字、遇到不可選取的 Canvas、網站禁止顯示修改，或內容涉及別人的聊天與私人文件：**保留原文、不建立專用腳本、不抓取素材、不公開上傳截圖與對話**。使用者可在合法條件下改用自行撰寫的離線範例練習。
