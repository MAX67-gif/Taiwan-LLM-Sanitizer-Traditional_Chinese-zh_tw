# R17 — Grafo de confianza de documentos sin conexión

> R17-P0 v0.1.0 · SHADOW / OFFLINE / NO SOURCE WRITE · HUMAN_TRANSLATION_REVIEW=PENDING

Uso: abre el HTML independiente en tu equipo, elige una carpeta y marca explícitamente los documentos Markdown cuya lectura autorizas. Los archivos no seleccionados no se leen.

PASS valida enlaces y anclas conforme a reglas conservadoras; WARN indica diferencias como mayúsculas; BLOCK señala rutas inseguras o destinos ausentes confirmados; UNKNOWN indica enlaces externos, archivos no seleccionados o sintaxis no comprendida. UNKNOWN no es éxito.

Para inspeccionar rutas reales y enlaces simbólicos usa el CLI opcional de Node. El selector del navegador no ofrece garantías de seguridad a nivel del sistema operativo. El informe omite el texto original, pero los hashes podrían ser identificables.

No es traductor, revisor semántico, certificado de permisos legales, firma digital ni editor. No hay peticiones de red ni cambios al original. Solo Markdown autorizado explícitamente.

Revisión humana por hablantes nativos: NO VERIFICADA.
