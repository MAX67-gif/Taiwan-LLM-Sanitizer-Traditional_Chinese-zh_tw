# 臺灣介面動詞慣例｜R13

依使用者 2026-10-25 明確指示，滑鼠／按鈕／選項的 `click` 應優先譯為**點選**，避免以「點擊」作為預設介面動詞。

| 原文或舊用語 | 明確 UI 操作建議 | 不應強制修改的反例 |
| --- | --- | --- |
| Click the button | 點選按鈕 | a click sound → 喀噠聲／點按聲，依語境 |
| 点击「设置」 | 點選「設定」 | 点击率／點擊率 → 行銷統計指標，不能替換成「點選率」 |
| 點擊「主選單」 | 點選「主選單」 | 觸控、雙擊、長按有獨立動作語意，不能隨便同義化 |

此為**使用者偏好、不是所有臺灣人士唯一正確的標準**。R3 原本 `点击 → 點擊` 待審候選和 R9/R10 既有正反例不回填重寫，避免破壞舊結果來源與追溯；新的偏好在 R13 的獨立詞彙資料與 R11 個人設定檔中表達。匯入 R11 Profile 需要使用者確認；正式自動套用權限仍由個別網站及逐筆勾選控制。
