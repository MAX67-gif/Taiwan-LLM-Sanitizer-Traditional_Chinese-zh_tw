# R17｜オフライン文書信頼グラフ

> R17-P0 v0.1.0 · SHADOW / OFFLINE / NO SOURCE WRITE · HUMAN_TRANSLATION_REVIEW=PENDING

使い方：単一 HTML をローカルで開き、フォルダーを選択して、読み取りを許可する Markdown 文書を個別にチェックします。選択していない文書は読み取りません。

PASS は限定的な相対リンクとアンカーの検証、WARN は大文字小文字の不一致など、BLOCK は確認できた不正経路や欠損、UNKNOWN は未検査の外部リンク・未許可対象・未知の記法を示します。UNKNOWN は成功ではありません。

シンボリックリンクと実際のファイル経路の厳密な検査には任意の Node CLI を使用してください。ブラウザー選択は OS の安全境界ではありません。レポートに本文は含まれませんが、ハッシュを推測される可能性があります。

自動翻訳、意味や法律上の権利の認証、デジタル署名、ファイルの書換えには対応しません。通信や原文の送信は行いません。対象は許可済み Markdown のみです。

人間の母語話者による翻訳校正：未検証。
