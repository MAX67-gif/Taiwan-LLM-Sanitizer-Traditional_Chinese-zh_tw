# R17｜오프라인 문서 신뢰 그래프

> R17-P0 v0.1.0 · SHADOW / OFFLINE / NO SOURCE WRITE · HUMAN_TRANSLATION_REVIEW=PENDING

사용 방법: 단일 HTML을 로컬에서 열고 폴더를 고른 뒤 읽기를 허용할 Markdown 파일을 명시적으로 선택합니다. 선택하지 않은 파일은 읽지 않습니다.

PASS는 제한된 링크·앵커 확인, WARN은 대소문자 불일치 가능성, BLOCK은 확인된 누락·위험한 경로, UNKNOWN은 외부 링크·미선택 대상·지원되지 않는 문법을 뜻합니다. UNKNOWN은 통과가 아닙니다.

실제 경로 및 심볼릭 링크 확인에는 선택형 Node CLI를 사용하세요. 브라우저 폴더 선택은 운영체제 수준의 보안 장벽이 아닙니다. 보고서에는 원문이 없지만 해시로 정보를 추측할 위험은 남습니다.

자동 번역, 의미/법적 권리 인증, 디지털 서명 또는 원본 수정 도구가 아닙니다. 네트워크 요청이 없고 명시적으로 선택한 Markdown만 처리합니다.

원어민 인적 번역 검수: 미검증.
