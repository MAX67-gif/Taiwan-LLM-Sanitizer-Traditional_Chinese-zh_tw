# R19｜獨立工程預覽的發行條件

R19 的單檔 HTML 與完整原始碼候選可以供審閱；不能把它們稱為新的正式 All-Tools Suite。原有 Suite 17.3.0 的 28 個工具身分與固定資產不因本預覽而改變。

## 提升為正式公開版本前

1. 在最終候選 tree 上通過所有相關 Node、Python、公開檔案、權利、六語同步與 generated-artifact parity 檢查。
2. 取得 R19 原生 Chromium 的實際收據，涵蓋匯入、取消、來源改變、過期預覽、偏好、候選超限、真實下載、窄版、鍵盤及零外部請求。未執行時保留 `NOT_RUN`。
3. 若合入會走產品發行路線，先完成新 Suite registry、版本、完整工具及所有資產登記。不得讓 R19 或品牌變更套用文件專用的免發版例外。
4. 保留全部合法受支援的舊工具與其原版號、來源 SHA 及固定 bytes。不得重建取代舊發行資產，也不得恢復已撤回的整合 ZIP。
5. 最終 PR 的必要 CI 成功後才評估合併；正式發布須完成 Draft 所有附件實際下載核對、公開後再下載核對。不以本機測試、API metadata 或 skipped publisher job 宣稱正式發布成功。

R19 沒有更換核心、擴充未審詞庫、連線 Provider 或開啟遙測。偏好只是使用者主動記下的提示，每一處仍須確認。任何更廣功能都需自己的範圍、同意、測例與發行驗證。

母語品質與使用者採用證據是獨立事項，不因工程 Gate 成功而自動通過。
