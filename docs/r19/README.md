# R19｜看上下文，逐處決定臺灣用語

R19 是獨立的本機工程預覽，使用原封不動的 R17.2 修稿引擎。它改善逐項判讀、檔案匯入與差異檢查；不是新的全文翻譯模型，也尚未成為正式 All-Tools Suite 版本。

[English](README.en.md) · [測試與驗證邊界](TESTING.md) · [發行條件](RELEASE_GATE.md)

## 開始使用

1. 將 `TW_First_Result_Studio_R19_20261101.html` 下載到自己的電腦，再用瀏覽器開啟。GitHub 的 HTML 原始碼頁不會執行工具。完整原始碼包內的位置是 `examples/TW_First_Result_Studio_R19_20261101.html`。
2. 按「直接體驗第一份修稿」，或匯入自己有權編輯的 UTF-8 `.md`、`.markdown`、`.txt`。匯入後仍要按「使用這份檔案」，才會取代畫面上的稿件。
3. 每張候選卡會顯示原稿所在行、欄位及附近文字。依真實語境選擇用詞，或保留原文；再產生預覽、核對差異與全文，下載新的 `.md`。

工具不覆寫磁碟原檔。不做選擇的候選會保持原文。兩個原創範例入口在已有工作時都要求確認切換，取消會保留目前稿件。

## 每一處都有自己的語境

例如同一份文件中的「介面的 menu」與「午餐的 menu」，可以分別確認為「選單」與「菜單」。顯示上下文是為了協助你判斷；工具沒有自動推論這一處是哪一種語境。

候選位置沿用引擎的 UTF-16 座標；畫面則以 1 起算的行數與 Unicode 字元欄位呈現。每個片段最多顯示同一行左右各 72 個 Unicode 字元，省略的文字以「…」標示。程式以純文字顯示原稿，不把原稿內的 HTML 當成頁面內容執行。

## 可選的文件用詞偏好

在某一處確認用詞後，可按「記住此語境的用詞」。這只把已提供的選項記在目前文件的記憶體中，讓其他相同原詞的候選顯示參考提示。不同語境的偏好可以並存，例如 UI 使用「選單」、餐飲使用「菜單」。

- 偏好不會自動勾選、批次替換、改變「保留原文」，也不會擴充凍結詞庫。
- 你仍要確認每一處實際語境。提示的存在不代表工具已判定語境相同。
- 可隨時清除偏好。編輯、清除、重新匯入原稿或切換範例會清掉文件偏好；關閉頁面後不保存。
- 增加或清除偏好會使舊預覽與計數摘要失效，須重新產生。已做出的逐項選擇不會因此改變。

這不是可載入任意詞庫的 glossary 管理器，也沒有跨文件永久偏好。

## 候選上限與差異摘要

引擎每次最多列出 120 處候選。假如偵測到 130 處，即使已處理畫面的 120 處，仍會提示另有 10 處未列出、未審核。預覽與下載摘要會標示 `PARTIAL`；沒有列出的內容保持原文。請分段處理剩餘內容，最後核對全文。

差異摘要最多列出 12 個有變更的行，每行顯示第一處實際差異附近的片段。300 字後的修改仍可見；同一行較後面的其他修改可能被省略，因此摘要不能取代全文檢查。

## 匯入與換行

檔案上限為 65,536 bytes。解碼前即拒絕 UTF-8 BOM，並拒絕無效 UTF-8、NUL、空白檔案及尺寸不一致。被拒絕或取消的匯入不會清除目前原稿、決策與預覽。

匯入的 CRLF／CR／LF 換行會保留在下載新稿中，只要沒有手動編輯原稿框。瀏覽器文字框的值會正規化為 LF；一旦手動編輯，介面會明示本次輸出改用 LF，磁碟原檔仍不更動。

## 隱私與摘要

原稿、上下文、偏好及結果只存在目前頁面的記憶體。沒有自動網路傳輸、外部字型、模型、帳號或持久儲存。手動前往公開回饋連結時則會開啟 GitHub，由你決定是否提交。

下載的 JSON 是本次操作的計數紀錄，不是語意品質認證。它包含偵測、列出、未列出、採用、保留、未決定等數量及文件偏好數量，不含原稿、譯文、偏好詞、檔名、檔案路徑、來源雜湊或帳號。

`ALL_DETECTED_CANDIDATES_SHOWN` 只表示本次引擎偵測的候選都已列出；不代表每一處已選擇、全文沒有其他問題，或原意已確認。

## 已知限制

67 個既有詞條與 9 個 overlay forms 維持原樣；未審 alias 仍是候選。凍結引擎可能拒絕含 JSON 的 fenced code，也會拒絕未閉合的程式碼區塊。這版不修改其結構判讀規則，不支援 PDF、OCR、完整 AST 或全文自動翻譯。工程測試不是母語審稿、自然度比較、使用者採用或外部平台隱私保證。

原生瀏覽器的新增驗收腳本已提供，必須取得實際執行收據後才能宣稱該項通過；詳見測試與發行條件。
