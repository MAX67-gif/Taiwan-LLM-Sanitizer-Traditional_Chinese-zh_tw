# R17.7 MRFT｜多框固定區域閱讀與翻譯預覽

**工具版本 0.1.0 · Chrome Manifest V3 獨立 Preview · 完整套件 Suite 17.3.0。**

在公開、非敏感的一般網頁上，框住你想持續閱讀的位置。每個框各自顯示原文與譯文，可以跟隨原網頁元素，也可以固定在螢幕位置。原網頁文字不改寫；最多同時 8 框。

預設使用**手動貼入譯文**。有相容且可用的本機 Translator API 時，才可明確啟用本機翻譯；無模型時會顯示原因。這是 DOM 閱讀預覽，尚不代表一般網站相容性、臺灣用語自然度或真人翻譯品質認證。

## 下載與安裝

1. 開啟 [Suite 17.3.0 正式下載頁](https://github.com/MAX67-gif/Taiwan-LLM-Sanitizer-Traditional_Chinese-zh_tw/releases/tag/all-tools-suite-v17.3.0)，下載 `TLS_Chrome_MV3_MRFT_R177_20261031.zip`；也可從完整套件 `TLS_ALL_TOOLS_SUITE_17_3_0.zip` 取得同一份安裝檔。
2. 解壓安裝 ZIP。在桌面 Chrome 開啟 `chrome://extensions`，啟用開發人員模式，點選「載入未封裝項目」，選擇包含 `manifest.json` 的資料夾。這不是 Chrome Web Store 已上架版本。
3. 開啟你有權閱讀且不含敏感資訊的普通 HTTP(S) 網頁。點選 MRFT 擴充功能圖示，確認目前網站與公開內容聲明，再啟用目前分頁。
4. 面板出現後再新增框。重新載入或導向新頁面後，必須重新明確啟用；不會自動在其他分頁或網站常駐閱讀。

原有 R5/R11/R13 安裝檔各自保持原版。避免同一頁同時啟用其他會改寫 DOM 的工具，造成框選來源不斷變動。

## 完成第一次多框閱讀

1. 在面板選擇位置模式，再點選新增翻譯框，拖曳包住一小段可見的一般段落。太小、沒有文字或超出安全限制的框會顯示原因，不會猜測鄰近文字。
2. 建立第二、第三個框。各框可設定來源與目標語言、移動與調整大小；狀態和譯文彼此獨立。
3. 手動模式：查看目前框內原文，貼入你取得且有權使用的譯文。原文或框的位置改變後，舊譯文失效，請重新確認。
4. 本機模式：選擇本機翻譯並明確準備模型。若瀏覽器回報需要下載，先確認下載提示並同意，再由按鈕啟動。沒有相容能力時顯示 `MODEL_UNAVAILABLE`，可繼續手動模式。
5. 用單框暫停、刪除或全部關閉結束。關閉會移除這個工具的框、監聽與觀察器，清除工作階段中的原文與譯文。已自行複製到剪貼簿的內容由你保管。

### 兩種位置模式

| 模式 | 捲動時發生什麼 | 適合的情況 |
| --- | --- | --- |
| `FOLLOW_DOM` 跟隨元素 | 框跟著最初選中的原網頁元素移動 | 持續閱讀同一段會更新的文字 |
| `FIX_VIEWPORT` 固定螢幕 | 框停在 CSS 像素座標，重新讀取進入該位置的可見文字 | 你刻意想觀察固定畫面區域 |

若跟隨的元素被移除、換成另一個元素，或可辨識的身分標記改變，會顯示 `NEEDS_REBIND`。請重新框選；工具不會憑相似選擇器偷偷改抓別的元素。一般 DOM 無法辨識所有「同一元素被網站重用」的情況，故不適合私人聊天、帳戶或虛擬化敏感資料清單。

## 本機模型與資料路徑

Chrome 的 Translator API 具有能力與語言組檢查，也可能需要先下載語言模型；能否使用仍取決於瀏覽器、裝置、網站政策及實際執行環境。MRFT 只在使用者明確準備時呼叫模型建立流程；DOM 更新不會偷偷下載模型。官方技術說明：[Translator API](https://developer.chrome.com/docs/ai/translator-api)、[Chrome extensions and AI](https://developer.chrome.com/docs/extensions/ai)。

MRFT 不建立遠端翻譯連線、不讀 Cookie／網站儲存空間、不收集遙測，也不把原文存進擴充功能儲存空間。模型套件下載本身可能連線；原網頁自己的網路行為不受 MRFT 控制。自動化測試中的模擬翻譯器只檢查取消與隔離機制，**不是實際模型語言能力的證據**。

原文改變、移動或調整框、切換語言／模式、暫停、重新框選、移除或關閉時，過期的非同步結果不應重新顯示。若工作逾時或模型失敗，面板顯示狀態，保留使用者重新操作的選擇。

## 原創練習頁

安裝 ZIP 附有原創動態練習頁；原始碼版本位於 [MRFT_ORIGINAL_FIXTURE.html](MRFT_ORIGINAL_FIXTURE.html)。它使用與擴充功能相同的多框模組，並提供動態文字、捲動、元素替換及排除區域，供重現操作。

原始碼練習可在專案根目錄執行 `python -m http.server 8000 --bind 127.0.0.1`，再開啟 `http://127.0.0.1:8000/docs/mrft/MRFT_ORIGINAL_FIXTURE.html`。仍須在頁面明確啟用。練習頁沒有假裝成真實模型的示範翻譯器；本機能力不可用時請使用手動譯文。ZIP 內練習入口與啟動方式以隨附安裝說明為準。

## 明確限制

- 只處理目前頂層頁面的普通可見 DOM 文字；不進入 iframe 或 Shadow DOM，不讀 OCR、圖片、Canvas/WebGL、影片字幕像素或螢幕畫面。
- 表單、密碼、可編輯內容、隱藏區、程式碼，以及可辨識的聊天／帳戶／付款／私人標記會先被排除。網站沒有正確標記的私人內容不一定可被辨識；因此只在已確認公開且非敏感的內容使用。
- 框太大、文字或節點超過上限時會停止該次擷取，不能把部分擷取冒充完整翻譯。重疊框彼此獨立，可能各自讀取相同的一小段公開文字。
- 手機尺寸的原創頁測試只驗證版面與指標操作，不表示 Chrome Android 可以安裝此擴充功能。瀏覽器縮放與網站特殊排版仍有相容性邊界。
- 原文資料與幾何只存在本次記憶體工作階段；沒有網站設定、原文雜湊、截圖或全文匯出。內部診斷只包含必要的計數與狀態，不構成匿名人類採用研究。
- 第三方內容的使用權與網站條款仍需自行確認；MIT 僅涵蓋本專案有權授權的程式與原創範例。參閱 [第三方權利政策](../THIRD_PARTY_RIGHTS_POLICY.md) 與 [隱私政策](../../PRIVACY.md)。

## 版本、驗收與回復

R17.7 是這輪工程名稱；MRFT 安裝工具為 0.1.0，完整 Suite 為 17.3.0。新套件保留原 27 項工具的版本及位元組，加入這個獨立 Chrome 預覽，總計 28 工具、23 個獨立工具資產及 28 個 Release 附件。既有 Suite 17.2.0／歷史標籤不覆寫。

驗收包含核心狀態、延遲結果、模型失敗、真實 Chromium 框選、敏感區排除、DOM 身分、原文不改寫、關閉回收與完整套件檢查。通過工程測試不等於真人使用成功率或翻譯品質。若需要停用，先全部關閉，再於 `chrome://extensions` 停用或移除 MRFT；原網站和舊版工具不依賴它。

開發者可查閱 [工作階段診斷 JSON Schema](session_metadata.schema.json)。核心 `metadata()` 只回傳來源網站的 origin、狀態、區域數、語言組及版本序號；不含原文、譯文、雜湊或網址路徑。內部 `getRegion()`／`listRegions()` 包含畫面所需的記憶體文字，不是可記錄或傳送的診斷介面。
