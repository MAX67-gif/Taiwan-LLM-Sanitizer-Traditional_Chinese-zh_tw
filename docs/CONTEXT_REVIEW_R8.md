# R8｜臺灣語境審查工作台（獨立 Preview）

2026-10-24。這是保守、不自動改寫原文的獨立實驗功能；通用擴充功能正式 runtime 仍為 R5 v0.4.0。保留 R6 的 100 題凍結品質題庫與 R7.1 的獨立示範，不互相混合。

## 產品行為

開啟 examples/TW_Context_Review_Lab_R8_20261024.html，直接貼上文字，選擇領域，再按檢視。使用原始詞庫 883 筆候選和 67 筆編輯種子；候選**只有建議，不會提升為自動生效的規則**。例如 menu 在 UI 領域是選單，在餐飲是菜單；domain=auto 會明確警示可能有多種意思。輸入不會透過工具傳到任何外部伺服器。

採最長詞優先匹配，保護常見 Markdown fenced/inline code、網址、HTML tag、script/style block、JSON key、插值佔位符。最多處理 12,000 字元、列出前 100 個位置，避免長頁卡頓；不涵蓋所有語法、專有名稱或真正自然語言推論，不保證發現的每一個詞都有正確答案。

## 版權與非文字獄原則

任何地區用語都不視為禁語。提交時要指出原文、建議說法、使用情境、正例及反例、原創或有權使用的來源；不得整包匯入禁止商用／禁止改作的第三方詞庫，也不得貼入私人網站資料或客戶文件。使用者永遠可忽略建議與保留原文。

## 驗收與維護

- 執行 node tools/build_context_review_r8.js --check 驗證可重現單檔，或不帶 --check 重新產生公開 HTML。
- 執行 node --test tests/test_term_review_r8.js 驗證歧義、最長匹配與語法保護。
- 執行 python tests/test_context_review_r8.py，需已安裝 Playwright/Chromium，確認本機使用者流程無外部請求。
- 不會因單次離線詞庫命中就宣稱真人自然度、模型品質或新詞條語意已驗證。
