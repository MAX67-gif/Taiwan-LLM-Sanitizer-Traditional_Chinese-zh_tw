# 目前功能與限制

Taiwan-LLM-Sanitizer **R5 0.4.0 為實驗性預覽版本**。我們會分清楚「已實作」、「部分支援」與「構想」，讓你知道實際可以做什麼。

| 能力 | 狀態 | 說明 |
| --- | --- | --- |
| Chrome MV3 逐站啟用／停用 | **原型可用** | 需使用者授權，支援一般 HTTP(S) 網頁 |
| Tampermonkey 單檔安裝 | **原型可用** | 個人設定及停用還原，無遠端腳本依賴 |
| 離線臺灣用語與簡短 UI 詞校正 | **原型可用** | 不代表全文譯文品質保證 |
| Chrome 本機 Translator API | **實驗性** | 可用性及模型下載依瀏覽器、語言組合與硬體而異 |
| 動態 DOM 更新與局部還原 | **部分支援** | 對高度客製網頁仍可能有差異 |
| 使用者四段臺灣用語偏好 | **原型可用** | 保留原用語／輕度／自然平衡／臺灣優先 |
| 正式、自然、口語等文風 | **僅可設定偏好** | 目前本機 API 未提供可驗證的對應文風控制 |
| R13 選取文字安全雙語閱讀 | **獨立 v0.6.0 Preview** | Chrome／Tampermonkey 逐站手動啟用、封閉面板原文對照與可選本機 Translator；不修改網頁原文、無雲端 Provider |
| R12 離線品質證據工作台 | **獨立研究工具可用** | 本機載入 R6 模型候選/人工評分、雙候選覆蓋與結構檢查；未驗證模型真實身分、自然度或獨立真人評審 |
| R11 個人詞庫逐站預覽／套用／還原 | **獨立 v0.5.0 Preview** | Chrome 和 Tampermonkey 共用 R9 schema；逐筆人工勾選，R5 舊版完整保留，不自動套用 R3/R10 研究詞庫 |
| R10 原創語境來源追溯與人工審查 | **獨立離線預覽可用** | 40 筆尚未獨立審核的正反例，追溯 R9 來源、手動決策及受 SHA256 綁定的 JSON；完全不授權自動翻譯 |
| R9 個人選詞／本機匯出／原文對照 | **獨立預覽可用** | 必須人工選擇；逐位置預覽、保存本頁記憶體及 JSON 備份；尚未整合 R5 runtime |
| R8 本機語境審查工作台 | **獨立預覽可用** | 單檔 HTML、可辨別一詞多義、不自動改寫、不送出輸入文字 |
| 883 筆詞庫候選 | **可查詢，不自動替換** | 16 類；還需要社群／專業驗證 |
| 67 筆編輯種子詞 | **保守啟用** | 遇歧義保留原文，部分需明確領域 |
| Markdown／TXT／JSON／JSONL CLI | **保守原型** | 以詞彙校正為主，JSON 字串修改需手動選用 |
| 網頁雙語 Overlay、滑鼠懸停原文 | **尚未提供** | 仍需實際介面與效能測試 |
| OCR、Canvas、WebGL、圖片、PDF 完整處理 | **尚未提供** | 需要不同的讀取與呈現技術 |
| 手機瀏覽器完整適配／Chrome 商店發布 | **尚未驗證** | 示範頁可在手機瀏覽，但擴充功能不代表手機全面可用 |

## R5 新能力

- **受保護專名：** 如 Codex for Open Source、Claude Code、GitHub，對已知原文保留正式名稱；模型回傳損壞時不強制顯示壞結果。
- **清楚的翻譯進度：** 固定圓形處理／完成／警示圖示；不宣稱有精確的整頁完成百分比。
- **Codex／Claude 工作流：** 有公開的共用 Skill 與離線翻譯後 QA，並非 AI 模型或雲端代理。
- **版本化 Chrome ZIP：** GitHub Actions／Releases 產生打包可解壓載入的擴充功能，**不是 Chrome Web Store 官方上架或可雙擊的 CRX**。

**我們不審查或禁止任何地區的中文用語。** 「臺灣繁體中文」指目標閱讀偏好，不是對語言的正確性評分。

完整使用方法見 [首頁 README](../README.md)。若想提出建議，請透過 GitHub Issue/PR；請不要貼出私人文件或敏感頁面文字。
