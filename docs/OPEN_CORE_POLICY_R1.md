# 開源授權與 Open-Core 政策 R1

**選擇來源**：原討論第六輪確認的 **方案 B：Open-Core**，非「AI Benchmark 方案 B」。本檔為專案治理與授權範圍說明，不構成個別案件法律意見。

## 已發布的 MIT 核心

1. 本公開 Repository 之自有原創程式、文件、示範詞庫，在沒有其他明確授權註記時依根目錄 [LICENSE](../LICENSE) 的 MIT 條款提供。
2. MIT 可免費使用、複製、修改、合併、發表、散布、再授權與販售，**包含企業和商業使用**；需保留授權及版權聲明。發布者不得事後對已按 MIT 取得的版本追溯加商用限制。
3. 本倉庫不得聲稱「只允許非營利」又在同一核心適用 MIT，也不得聲稱「最高解釋權可凌駕授權」。官方版與商業版的識別與商標須分開。
4. 不得將 BSL 或禁止商用的內容稱為 OSI 定義的開源，也不能將第三方原始碼／翻譯作為 MIT 本人作品發布。

## 商業邊界

可在未來另外提供：特定領域專業字典、企業 SSO／合規連接器、私有託管、服務 SLA、人工校對、獨立原創商業模組。**這些資產必須與公開 MIT 元件分檔、分套件、分授權，無須現在建立私有 Repo 或把商業代碼交給 OSS 贊助流程。**

禁止在 GitHub 上傳未授權的專業資料、遊戲資產、憑證、客戶資料。詞典中「常用字／事實」不必然有獨立著作權，專業資料若主張營業秘密應採取有效保密措施。

## 貢獻者及第三方

- 對外 PR 貢獻需有合法授權並同意貢獻作品以 MIT 發布；著作權原則上仍歸各合法權利人。
- 未得到貢獻者明確同意，不可擅自把其 MIT 之外的原創貢獻放入私有商業版；若要重授權需另有合適權利來源。
- 採第三方資源要先記錄 `name/source/license/attribution/redistribution_scope`；翻譯可能涉及改作與再散布權，不能僅因資料可上網取得便重發。
- 對 AI 生成內容須做人為審核及來源掃描；AI 產出不保證當然構成臺灣法律上的著作權作品。
- 專案名稱及 Logo 的可能商標權與公開碼 MIT 授權分開；但不可禁止合法的必要署名或符合規則的合理提及。
- 未來商業客戶使用條款、退款、資料處理約定與商標授權另由專業人士檢閱。

## OpenAI 資源隔離

Codex for OSS 的 API credits 只用於符合計畫條款的開源核心開發、審查、測試、維護與發布流程，不預設可用於私有字典商品研發；所有使用紀錄應可稽核。不得申報不存在的使用者、下載量或 PR 維護負擔。
