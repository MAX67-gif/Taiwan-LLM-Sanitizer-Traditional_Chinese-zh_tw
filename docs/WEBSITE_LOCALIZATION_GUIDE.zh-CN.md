# 通用网站翻译与双语阅读｜简体中文说明

**语言：** [繁體中文指南](WEBSITE_LOCALIZATION_GUIDE.md) · [简体中文指南](WEBSITE_LOCALIZATION_GUIDE.zh-CN.md) · [九个实际场景示例](USAGE_EXAMPLES.zh-CN.md)

> 本页是台湾繁体中文本地化工具的使用指导，不是任何第三方网站或游戏的官方插件、安装包或授权声明。所有示例都使用原创的虚构内容。

## 1. 先决定是否允许使用

确认网站服务条款、内容版权和个人隐私界限。**能看到网页不代表可以复制、翻译后重新发布或修改网站。** 不要处理他人的私信、聊天、玩家身份、账户、支付或未经许可的长篇作品；不绕过游戏的防作弊机制和运行限制。

## 2. R13：手动选择文本并对照

在网站中选择自己有权阅读的普通可见文字，通过 R13 显示原文与候选译文。示例：`Open settings to adjust the display.` → `開啟設定以調整顯示方式。`（人工示例，不是模型的实测输出）。本机翻译功能能否使用，取决于浏览器、设备和语言模型的实际可用性。**这并非整站自动翻译，也不会修改网页原文。**

## 3. R11：用户自己决定术语

在网站允许的前提下，按站点管理自建用语，预览并人工确认。台湾 UI 中 `menu → 選單`、餐饮 `menu → 菜單` 的语境不同，不应全局替换。用户可以停用并在满足条件时恢复显示。

## 4. R14／R15：能力告知和结构保真

R14 只提供离线的模型能力／授权声明检查，不负责实际调用云端。R15 可以分析 Markdown、JSON、Prompt 等自有技术文档，并在人工提出修改前保护代码、URL、数据结构和变量；**不自动翻译，也不覆盖源文件**。R15.1 是否发布以正式 [GitHub Releases](https://github.com/MAX67-gif/Taiwan-LLM-Sanitizer-Traditional_Chinese-zh_tw/releases) 为准。

## 5. 网页游戏式网站：能做什么、不能做什么

在虚构网页游戏里，如果按钮 `Open settings` 是普通、可选择的 HTML／DOM 文字，用户也拥有合法使用权，则**可能**通过 R13 进行只读对照，或者通过 R11 手动管理自己的术语。若内容由 Canvas/WebGL／图片绘制，则现有工具**不支持直接翻译**。游戏聊天、昵称、账户、存档、网络封包均排除。我们不提供任何特定游戏的词库、脚本、补丁或下载；不承诺真实游戏兼容性。

## 6. 从示例学习而不是复制第三方素材

推荐从 [九个原创使用示例](USAGE_EXAMPLES.zh-CN.md) 开始，再阅读 [第三方权利与隐私政策（繁体中文）](THIRD_PARTY_RIGHTS_POLICY.md)。如需提交反馈，只分享自己有权公开的合成样本及去识别化结果，不要上传真实游戏素材、聊天记录或授权不明的翻译文案。
