# R11｜逐站個人詞庫：預覽、明確套用與可還原（v0.5.0 Preview）

> 臺灣繁中使用者可直接安裝的加法式預覽版本。MIT 公開核心；CA L. 為 Founder / Project Steward。2026-10-25。
>
> **R5 v0.4.0 完整保留，不覆寫既有 Release；R11 是另一份獨立發布的 v0.5.0 預覽安裝檔。**

## 為什麼做 R11？

R9 讓使用者離線保存自己偏好的詞彙，但沒有實際修改網站；R10 讓人閱讀詞彙的語境正反例、來源與風險，但明確沒有自動執行權。R11 只打通「R9 **使用者自己明確保存的詞彙** → **目前授權的單一網站** → **預覽具體位置** → **逐項人工勾選** → **套用** → **還原**」的最小可用路徑。

R3 的 883 筆候選、67 筆編輯種子和 R10 的 40 筆人工示例**不會自動取得任何額外替換權限**。R11 不執行雲端模型或上傳使用者頁面內容，不能因此宣稱自然中文模型品質已提升。

## Chrome 安裝與使用（無須修改程式）

1. 從 R11 GitHub Release 下載 Chrome ZIP，解壓後在 `chrome://extensions` 選「載入未封裝項目」，指定該解壓後包含 `manifest.json` 的資料夾。這是 Preview，尚未取得 Chrome Web Store 核准。
2. 開啟想要處理的普通 HTTP(S) 網站，在 Chrome 擴充功能按「啟用本站」，明確授予該網站存取權限。沒有逐站授權時，R11 無法預覽或套用。
3. 使用 R9 離線 HTML 工作台手動匯出 `tls.personal-glossary.v1` JSON。在 R11 的「匯入 R9 個人詞庫 JSON」選擇此檔。檔案內容只保存在此瀏覽器的 **目前網站 origin 專屬本機設定**；不會跨站套用。
4. 如詞彙有語境歧義，先在「用語情境」選 UI、餐飲或其他明確領域。選「自動判斷」時只允許 `general` 類個人條目參與建議，絕不自動猜不確定的領域。
5. 按「掃描並預覽」，頁面本身不變，工作台顯示該頁符合保護規則的候選位置（最多掃描 100 處，Popup 最多展示前 60 處）。勾選每個確定要改的位置，再按「套用勾選」。沒有勾選就不修改。
6. 按「還原 R11」可還原仍保有 R11 最後修改結果的文字；若網站已自行更新，會跳過以免覆寫網站新內容。按「退出並恢復原翻譯」會退出 R11，回到原本 R5 的翻譯流程。

Chrome 個人詞庫使用 `chrome.storage.local`，儲存 key 含該站 `origin`。本機儲存**不代表零儲存**，也不等於資料加密或不能被持有瀏覽器設定存取權限的人看見。請勿匯入含密碼、帳號、客戶祕密的個人詞庫。

## Tampermonkey 安裝與使用

下載 `TLS_Tampermonkey_R11_20261025.user.js`，匯入 Tampermonkey。此檔 **完全自含**，不需 CDN、`@require` 或第二段手動啟動腳本。先從 Tampermonkey 選單「啟用本站」；打開右下角圓形按鈕，在 R11 區塊匯入 R9 個人詞庫，再按預覽、逐項勾選、套用或還原。亦可使用「TLS R11：開啟本站個人詞庫」選單；如果本站未啟用，不會自行展開或修改。已儲存的個人詞庫只依當前站點 origin 保存到 Tampermonkey 的 GM 本機設定。

**注意：** 不建議在同一網站同時啟用 R5 和 R11 兩套 Tampermonkey 腳本或 Chrome 擴充功能。請停用舊版後再使用 R11。R11 內已沿用 R5 翻譯核心，不需要同時安裝兩版。

## R11 結構安全與衝突規則

- 資料格式沿用 R9 的 `tls.personal-glossary.v1`；嚴格驗證上限 200 筆／64 KiB、schema、領域、字元與唯一性，不接受未知欄位或結構性注入。
- 一般詞彙 `general` 只在無更明確同名條目時提出建議；特定領域 `KEEP` 會覆蓋一般領域 `replace`，使用者指定「保留原詞」應優先於泛用建議。
- R11 僅掃描當前可見、非可編輯的**文字節點**：不修改 `input`、`textarea`、`select`、`contenteditable`、`script`、`code`、`pre`、隱藏元素、玩家/聊天欄位、專名、佔位符、模板語法、網址或含明顯結構標記的文字。為減少風險，目前也不修改 `title`、`aria-label`、`alt` 等屬性。這是保守的安全設計，並非「全站百分百文字皆可翻」。
- 預覽不寫入網站 DOM；要經使用者明確勾選並按套用。套用前重新確認每個文字節點、原文內容、位置與版次未變；**任何所選位置失效時整批拒絕**，需重新掃描。
- 只有工具先前確實修改、且目前仍等於其改寫後的文字才會被還原。網站在期間自行更改的文字不得被舊快照蓋掉。
- 切入 R11 時先停止 R5 非同步翻譯、取消舊任務並還原既有 R5 受控修改；離開 R11 才允許恢復原本 R5。兩條改寫鏈路不能同時修改同一頁。
- 每個分頁每次手動預覽/套用；網站重新整理後不會因為曾在該站選過偏好就自動套用。個人詞庫可持續本機保留，但**改寫授權不持久化**。

## 測試與證據邊界

- `python tools/build_r11.py`：共用 R5 核心來源編譯 Chrome/Tampermonkey + 完整 R11 單檔；固定 ZIP 時戳並附 SHA256。
- `python tools/build_r11.py --check`：確保已交付的 R11 產物與來源完全一致。
- `node --test tests/*.js`：含 R11 schema、領域優先、禁自動、字詞邊界及受保護文字測試。
- `python tests/test_site_glossary_browser_r11.py`：實際 Chromium 測試 R5/R11 互斥、預覽不修改、精確批准、網站自行改動、跨站拒絕、還原與回到 R5。
- `python tests/test_popup_browser_r11.py`：Chrome 使用者操作、站點授權、檔案匯入、預覽勾選及還原。
- `python tests/test_userscript_browser_r11.py`：獨立 userscript 與 GM 設定、明確逐站啟用。
- 完整既有 R1～R10 Node／Chromium 回歸、R6 frozen SHA／候選詞庫 parity、Publication Guard、ZIP CRC/SHA 均須通過才能發版。

CI 的測試環境不能取代所有真實網站、Chrome 本機 Translator API 語言包、真實 Tampermonkey 編輯與任意瀏覽器產品的相容性證據。**未取得真人語感正確率、獨立雙人審稿結果、Chrome Store 認證或所有網站 100% 相容證據。**

## 後續計畫與回滾

R12 優先測本機 Translator 真實語言模型、真人雙評審、客觀品質與一詞多義誤判。雙語閱讀／Hover 需要額外安全及無障礙測試。R11 發現缺陷時不必覆寫已發布的 R5/R6/R7/R8/R9/R10：停用 R11、退回已封存的 R5 v0.4.0，或以新 PR revert R11 新增檔案；不得 force push 或刪改已公開的 frozen 樣本。
