# AI 寫初稿，臺灣用詞由你決定

[English walkthrough](README.en.md) · [返回專案](../../README.md)

**同一個 `menu`，不同位置可以做不同決定。** 這份展示用既有、正式發布的 R17.2 離線工作台，重播原創 Markdown 的逐處選詞，並提供實際輸出供核對。它是技術功能示例；沒有真人用語品質評分，也沒有虛構使用者成效。

## 1. 先下載真正可用的工作台

**[開始第一份安全修稿：正式 Suite 17.2.0 Release](https://github.com/MAX67-gif/Taiwan-LLM-Sanitizer-Traditional_Chinese-zh_tw/releases/tag/all-tools-suite-v17.2.0)**

在 Release 的 **Assets** 下載 `TW_Wording_Assistant_R172_20261027.html`，用自己的瀏覽器開啟。也可下載完整 `TLS_ALL_TOOLS_SUITE_17_2_0.zip`，解壓後開 `START_HERE.html`。GitHub 的 HTML 原始碼頁不是已部署的線上工具。

## 2. 60 秒導覽：四個主要動作

「60 秒」指此導覽的設計長度，**不是量測過的真人完成時間**。第一次使用可以慢慢核對。

1. **載入原稿。** 打開 [source.md 原創練習稿](source.md)，用 GitHub 的 Download raw file 儲存為 UTF-8 `.md`。在工作台選檔載入，再點選「尋找臺灣用語建議」。請使用這份練習稿；內建「載入原創範例」是另一份示例。
2. **逐處決定。** 依下表採用 4 處、明確保留 2 處。另 2 處不選；沒有選擇時會保留原文。
3. **檢查預覽。** 點選「產生安全差異預覽」，核對 [實際 preview.md](preview.md)。原始輸入不會被覆寫。
4. **另存新稿。** 點選「下載新稿 .md」。下載內容仍可能包含你輸入的完整文件，請自行保管。改變任一選擇後，必須重新產生預覽才可匯出。

## 3. Before → 逐處決定 → 真實 Preview

| 原稿中的位置 | 你的操作 | 本次輸出 | 原因與界線 |
| --- | --- | --- | --- |
| `software menu` 的 `menu` | 採用「選單」（介面選單） | `software 選單` | 英文 `software` 沒有候選，保持原文；這不是完整英譯中 |
| 第一處 `軟件` | 採用「軟體」（軟體技術） | `軟體` | 有限詞庫建議，需使用者確認 |
| 第一處 `數據庫` | 採用「資料庫」（軟體技術） | `資料庫` | 只改這一處 |
| 餐廳的 `menu` | 採用「菜單」（餐飲菜單） | `菜單` | 與第一個 `menu` 分開決定 |
| `點擊率` 裡的 `點擊` | 不提供採用操作：`BLOCKED` | `點擊率` | 統計用詞不套用滑鼠「點選」 |
| 第三處 `menu` | 點選「保留這一處原文」 | `menu` | 明確保留高於其他出現位置的選擇 |
| 另一處 `軟件` | 點選「保留這一處原文」 | `軟件` | 不因前一處已選「軟體」而連動 |
| 最後的 `數據庫` | 不做選擇 | `數據庫` | `UNSELECTED` 預設保留，不等於已審稿 |

本次實際有 **8 個檢視項目、4 處採用、2 處明確保留、2 處未選（其中 1 處被阻擋）**。UI 的「2 個段落有更動」是變動段落數，不能誤寫成只有兩個詞被替換。

## 5. 重現與隱私

開發者在專案根目錄執行 `node tools/check_showcase_r176.js --check`，會用真正的 R17.2 核心重播並核對檔案；預設不寫回任何檔案。`tests/test_showcase_browser_r176.py` 另以 Chromium 真正操作既有 HTML，檢查輸入、選詞、預覽、下載、變更後預覽失效，以及沒有 HTTP(S) 外傳與頁面錯誤。

這個離線工作台沒有自動傳送原文或回饋。若你另將原稿交給 Codex／Claude／Grok，資料會依該平台的規則處理；不能把外部 AI 聊天稱為完全離線。見 [AI 協作教學](../AI_WORKFLOWS_CODEX_CLAUDE_GROK.md)。
