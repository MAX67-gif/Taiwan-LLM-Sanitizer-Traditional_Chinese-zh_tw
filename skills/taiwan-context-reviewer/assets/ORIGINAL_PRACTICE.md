# 自製練習：兩個 menu，兩種用法

請在 software menu 裡開啟設定。
餐廳 menu 中列出今日午餐。
請點擊按鈕後，再查看頁面的點擊率。
請把软件中的数据库、文件夹與鼠标說明寫得清楚。
不確定時，請保留原詞，不要自行猜測。

```js
const menu = "restaurant";
const databaseUrl = "https://example.org/docs/menu";
const greeting = "点击按钮";
```

這個連結的目的地應保持不變：[查看原始文件](https://example.org/docs/menu)。
變數 {{USER_PATH}} 與 ${HOME} 不應修改。
