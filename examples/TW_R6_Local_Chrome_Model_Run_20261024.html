R6 Chrome 本機模型評測

這是選用 Chrome 內建 Translator API 的**真實模型輸出工具**，不是由測試程式模擬翻譯結果。是否能啟動模型、語言包是否可下載，取決於你的桌面 Chrome 環境。R6 目前沒有在我們的 CI 上拿到真實本機語言模型翻譯品質結果。

隱私與重要限制

本頁沒有自己的伺服器，也不含外部 JS、追蹤、上傳或對外翻譯 API。你按下「開始」後，Chrome 可能自行下載本機語言模型。翻譯文字交由瀏覽器內建的 Translator API 處理，不會由本工具上傳至我們的服務。桌面 Chrome 才可能提供這個 API；手機 Chrome 不支援。讀取的檔案只存在本頁記憶體，請只選公開測試題，不要選個人文件。
